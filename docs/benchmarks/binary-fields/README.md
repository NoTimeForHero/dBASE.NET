# Чтение бинарных полей

База — чтение `BitConverter` по смещению из `c8f303b38cc2a9f19ecfc507f5eee3e5cdd85a79`. Три варианта читают по одному `Int32` и `Int64` из одного и того же невыровненного диапазона каждой из 10 000 синтетических записей. У всех вариантов есть проверка ширины поля. В подготовке каждого сценария проверены знаковые значения и порядок байтов на каждой записи. Файловые операции и упаковка значений `object` исключены из измерения. [Стенд](../../../dBASE.NET.Tests/benchmarks/Harbour/BinaryFieldBenchmarks.cs)

BenchmarkDotNet 0.15.8, Release, `net472` на .NET Framework 4.8.1 (4.8.9310.0), Windows x64. Один запуск, три итерации прогрева и восемь измерительных с целью 200 мс. Время приведено за проход по 10 000 записям. Один выброс базового сценария исключён BenchmarkDotNet.

| Чтение | Среднее ± `Error`, мкс | Ускорение |
| --- | ---: | ---: |
| `BitConverter` по смещению | 56,27 ± 2,28 | 1,00× |
| `Unsafe.ReadUnaligned` | 11,54 ± 0,41 | 4,88× |
| `BinaryPrimitives` Little Endian | 25,21 ± 0,58 | 2,23× |

Аллокаций в измеряемых операциях нет. Максимальный выигрыш в этом микробенчмарке составил 44,73 мкс на 20 000 чтений примитивов. Для масштаба полный проход по 10 000 реальных записей в предыдущем этапе занял 11,19 мс, причём в нём есть и другие типы полей, и ввод-вывод. Эффект на полный проход отдельно не измерялся. В библиотеке оставлен `BitConverter` без дополнительных зависимостей. Оба альтернативных API доступны стенду через зависимости BenchmarkDotNet.
