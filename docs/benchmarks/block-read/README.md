# Блочное чтение записей Harbour

19 ноября 2026 года. Замер сделан на рабочей копии на базе `6f8b87a10cc12d29c837874283a0b9ca8e5d4fad` с блочным чтением. `FastDbf.ReadRecords()` выдаёт полные записи. `FastDbf.ReadValues(idColumn, printedColumn)` выдаёт значения в порядке переданных столбцов, физический индекс и метку удаления. `Dbf.Read` использует тот же блоковый читатель для загрузки таблицы в память. [API FastDbf](../../../dBASE.NET/FastDbf.cs#L125), [блоковый читатель](../../../dBASE.NET/DbfRecordReader.cs)

Один проход использует буфер до 64 КиБ и готовит смещения и декодеры один раз. Для цели `net8.0` заполнение буфера использует `Stream.ReadAtLeast` со `Span<byte>`. Сборки для остальных целей используют цикл `Stream.Read`. Проверено, что локальный NuGet-пакет содержит DLL для `net462`, `net48`, `netstandard2.0` и `net8.0`. [Цели сборки](../../../dBASE.NET/dBASE.NET.csproj#L22), [Stream.ReadAtLeast](https://learn.microsoft.com/en-us/dotnet/api/system.io.stream.readatleast)

## Условия и результаты

Оба способа измерены в одной сборке на каждой платформе. Для полных записей сравниваются цикл `GetRecord` и `ReadRecords`. Для двух полей сравниваются два вызова `GetValue` на строку и `ReadValues`. Стенд проверяет совпадение контрольных сумм вне замера. Использована та же пара DBF/FPT Harbour на 10 000 записей, её SHA-256 сверены с базовым отчётом. BenchmarkDotNet 0.15.8, Release, один запуск, три итерации прогрева и восемь измерительных с целью 200 мс. [Условия базового замера](../efb9651/README.md), [сценарии стенда](../../../dBASE.NET.Tests/benchmarks/Harbour/HarbourReadBenchmarks.cs)

Время приведено как среднее ± `Error` BenchmarkDotNet за проход. Ускорение рассчитано как время индексного обхода, делённое на время блочного.

| Цель | Сценарий | Индексный → блочный, мс | Ускорение | Аллокации до → после, байт/строку |
| --- | --- | ---: | ---: | ---: |
| `net472` | Полные записи | 29,875 ± 1,141 → 19,292 ± 0,759 | 1,55× | 2 044,42 → 1 858,47 |
| `net472` | `ID` и `IS_PRINTED` | 20,056 ± 0,690 → 2,362 ± 0,099 | 8,49× | 271,98 → 246,50 |
| `net8.0` | Полные записи | 10,843 ± 2,022 → 9,061 ± 0,583 | 1,20× | 1 876,56 → 1 691,16 |
| `net8.0` | `ID` и `IS_PRINTED` | 1,785 ± 0,047 → 1,071 ± 0,055 | 1,67× | 223,99 → 198,59 |

Цель `net472` использовала DLL `net462` на .NET Framework 4.8.1 (4.8.9310.0), x64. Цель `net8.0` использовала DLL `net8.0` на .NET 8.0.0 (8.0.23.53103), x64. На .NET 8 интервалы времени для полного прохода пересекаются, а BenchmarkDotNet отметил итерации короче 100 мс. Для полного прохода коэффициент 1,20× отражает средние этой серии.
