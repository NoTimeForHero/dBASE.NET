# Случайное чтение из неизменяемого DBF

База сравнения — `FileStream` с буфером 4 КиБ, как при открытии файла в `FastDbf` на `57ff708cdb5a5c6e660b4082d5c054e28321f720`. Сравниваются чтение с этим буфером, точечное чтение через `BinaryReader` с его переиспользуемым буфером и `MemoryMappedFile` с `ReadInt64`. Каждый вариант открывает файл внутри замера. Для отображения также учитывается создание и закрытие представления. [Стенд](../../../dBASE.NET.Tests/benchmarks/Harbour/RandomReadBenchmarks.cs) · [Открытие FastDbf](../../../dBASE.NET/FastDbf.cs#L33)

Читаются ровно восемь байтов `PAY_DATE` по одной и той же фиксированной перестановке физических индексов. Для 128 чтений используется начало этой перестановки. Для 10 000 чтений каждый физический индекс используется один раз. До замера контрольная сумма совпала с ожидаемыми значениями во всех вариантах. Файл Harbour содержит 10 000 записей и открывался с `FileShare.Read` в измеряемых сценариях. Результаты относятся к прогретому файловому кэшу. Декодирование даты, чтение memo и создание объектов записей не входят в сравнение. [Фикстура](../efb9651/README.md)

BenchmarkDotNet 0.15.8, Release, `net472` на .NET Framework 4.8.1 (4.8.9310.0), Windows x64. Один запуск, три итерации прогрева и восемь измерительных с целью 200 мс. Время приведено за всю пачку запросов.

| Запросов | `FileStream` с 4 КиБ, мкс | Точечные чтения, мкс | `MemoryMappedFile`, мкс | Ускорение отображения к базе |
| ---: | ---: | ---: | ---: | ---: |
| 128 | 195,435 ± 8,259 | 181,445 ± 8,617 | 137,313 ± 3,141 | 1,42× |
| 10 000 | 14 178,132 ± 627,403 | 14 380,486 ± 1 396,540 | 685,407 ± 42,102 | 20,69× |

У точечных чтений и буферизованного `FileStream` интервалы времени пересекаются при обоих размерах пачки. Отображение заметно ускорило этот сценарий на неизменяемом файле. В библиотеке сохранён `FileStream`, поскольку `FastDbf` допускает изменения файла другим процессом через `FileShare.ReadWrite`. Все 109 обнаруженных тестов прошли.
