Исходный JSON финальной серии

Отчёты встроены в эту страницу. У сводки BenchmarkDotNet поле HostEnvironmentInfo описывает хост инструмента. Версия дочернего процесса указана рядом с каждым отчётом.

Как воспроизвести финальный срез

Соберите dBASE.NET в Release на ревизии 42ddfd0. В копии проекта стенда замените ProjectReference ссылками на готовые DLL. Для цели net472 укажите DLL net462, для net8.0 и запуска на .NET 10 — одну и ту же DLL net8.0. Запускайте Harbour и DBT в двух отдельных копиях стенда.

Перед измерением запустите выбранную фикстуру с --verify. Для DBT добавьте --dbt сразу после пути. В замере укажите --runtimes net472, net8.0 или net10.0, --launchCount 1 --warmupCount 3 --iterationCount 8 --iterationTime 200 --keepFiles и отберите методы из соответствующего JSON по Method. После замера сверьте SHA-256 DLL рядом с дочерним исполняемым файлом.
